README – Projet UniLogic / UniStream

Avant de commencer, il est fortement recommandé de lire notre rapport,
disponible à l’extérieur de ce projet. Il permet de comprendre le contexte
général, les choix techniques et l’architecture globale du système.

------------------------------------------------------------
1. Prise en main du logiciel UniLogic
------------------------------------------------------------

Pour apprendre à utiliser le logiciel UniLogic, commencez par lire le
tutoriel suivant :

- unilogic_unistream.pdf

Ce document contient tous les détails nécessaires pour la prise en main
du logiciel UniLogic et de l’automate UniStream.

Dans le dossier « Exemple Vérin », vous trouverez :
- le fichier ETS du Grafcet ;
- le projet UniLogic correspondant, prêt à être ouvert avec UniLogic.

------------------------------------------------------------
2. Tests des entrées / sorties
------------------------------------------------------------

Dans le dossier « Test Entrée Sortie », vous trouverez :
- un document PDF décrivant les entrées et sorties utilisées ;
- un projet UniLogic de test permettant de vérifier le bon fonctionnement
  des E/S.

------------------------------------------------------------
3. Importation des entrées / sorties dans UniLogic
------------------------------------------------------------

Afin d’éviter de redéfinir les entrées et sorties dans UniLogic à chaque
nouveau projet, le dossier « IO_Unilogic » contient :
- un fichier Excel pouvant être directement importé dans UniLogic.

Cela permet de standardiser la configuration des E/S et de gagner du temps
lors de la création de nouveaux projets.

------------------------------------------------------------
4. Projet UniLogic – Dernière version
------------------------------------------------------------

Le dossier « Projet Derniere Version » contient :
- le projet UniLogic dans sa **dernière version fonctionnelle** ;
- cette version a été **testée et validée** par notre équipe.

Pour comprendre l’état actuel du projet, il est recommandé de consulter :
- le bilan de tests, disponible à l’extérieur de ce dossier ;
- le rapport du projet, qui détaille la situation globale, les tâches
  restantes à réaliser ainsi que les points pouvant être améliorés ou
  modifiés.

------------------------------------------------------------
5. Fichiers LaTeX
------------------------------------------------------------

Le dossier « LATEX_Unilogic » contient :
- les fichiers LaTeX du tutoriel UniLogic mentionné précédemment ;
- les fichiers LaTeX du rapport final du projet.

Ces fichiers permettent de modifier, mettre à jour ou régénérer la
documentation du projet.
