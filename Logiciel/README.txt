Vous trouverez dans ce dossier le fichier exécutable (.exe) du logiciel Editsab.

Concernant UniLogic, le logiciel n’est pas fourni directement dans ce dossier.
Il doit être téléchargé depuis le site officiel à l’adresse suivante :
https://pl-systems.fr/logiciel-unilogic.html

Après vous être rendu sur cette page, veuillez télécharger le fichier
UniLogicSetup_1_38_Build_64.exe.

Il est également nécessaire de télécharger Code Composer Studio (CCS).
La version 12.8.1 est recommandée, car elle est la plus stable et fonctionnelle pour ce projet.

Pour exécuter le code MSP430, veuillez connecter le câble fourni entre la carte MSP et le PC.
Après avoir importé le projet (archive ZIP) dans CCS, lancez une session de débogage (Debug), puis cliquez sur « Resume » pour démarrer l’exécution du programme.

Avant toute manipulation, assurez-vous que :
- l’alimentation des moteurs est correctement branchée ;
- l’automate (API) est sous tension ;
- l’IHM est lancée.

Pour le lancement et la configuration de l’IHM, veuillez vous référer aux tutoriels PDF disponibles dans l’archive du projet.

Code Composer Studio est l’environnement de développement (IDE) fourni par Texas Instruments, utilisé pour la gestion et la programmation de l’ensemble du code lié au pilotage des moteurs.
